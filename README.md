# Xonados Novelas - Stremio Addon

Node.js addon exposing Xonados novela metadata and normal HTML video sources.

## Run
npm install
npm start

Addon:
http://localhost:7000/manifest.json

Deploy on Render:
- Build command: npm install
- Start command: npm start

Use only content/video sources you are authorized to access and redistribute. No DRM, authentication bypass, paywall bypass, or access-control circumvention is implemented.
